# Hyper 1.3.0

这是一次以剪贴板可靠性、隐私、性能和专业工作流为核心的阶段更新。

## 主要更新

- 新增敏感剪贴板策略：识别 concealed/transient、OTP 和私钥内容，支持跳过保存、自动过期、一次性粘贴，以及 15 分钟、1 小时或自定义临时隐私暂停。
- 新增可扩展全文搜索：支持拼音、模糊匹配、短语、否定条件，以及 `app:`、`type:`、`before:`、`after:`、`is:pinned`、`is:queued` 等组合查询。
- 新增加密 Smart Filters，可保存、重命名、应用和删除常用搜索条件。
- 重构剪贴板预览管线：缩略图在后台读取和解码，使用 32MiB 成本上限的 LRU 缓存，快速滚动和关闭面板时主动取消并释放资源。
- 新增 Paste As 与更完整的跨应用互操作，支持原始、富文本、RTF、HTML、纯文本及多文件拖放。
- 新增快捷键 Profiles、场景模板、导入导出和冲突解释。

## 稳定性与安全

- 剪贴板正文、载荷、缩略图、搜索分片和 Smart Filters 使用 Keychain 管理的 AES-GCM 静态加密。
- 存储改为事务型恢复模型，损坏索引会隔离并从可验证内容重建，不再静默丢失历史。
- 粘贴和 Paste Stack 使用两阶段提交；权限、目标应用、事件发送或队列持久化失败时不会错误出队。
- 使用 change-count CAS 恢复剪贴板，避免覆盖用户在粘贴期间新复制的内容。
- 捕获、搜索、预览和退出流程均采用有界异步任务，降低大内容、慢 provider 和退出竞态造成的卡顿或空壳记录。

## 性能门禁

- 5,000 条、每条约 32KB 的高唯一度搜索语料：候选收敛到 1 条，热/冷搜索 P95 低于 30ms。
- 搜索正文、索引结构及构建峰值均受 256MiB 硬上限约束。
- 1,000 张 720×720 图片快速滚动时，解码缓存保持在 32MiB 上限内，并在面板关闭后释放。
- 发布前整仓测试：339 项全部通过。

## 签名说明

本阶段版本继续使用 Hyper 既有的固定自签名证书，以保持现有用户的辅助功能授权与更新信任连续性；该构建未进行 Apple Developer ID 公证。
