# Hyper 30 项产品级优化战役状态

最后更新：2026-08-27

## 验收总则

清单冻结为恰好 30 项。每项必须至少满足以下一条：显著提升使用体验；显著提升稳定性或性能；显著缩小与全球顶级同类专业软件在完成度、功能覆盖、UI/UX 或工程质量上的差距。低价值微调不计数，不允许用新增第 31 项掩盖未完成项。

状态值：`待实施`、`实施中`、`待独立审查`、`待视觉签认`、`已通过`、`阻塞`。

## 固定清单（30/30）

### A. 发布、安全与工程底座

1. **仓库凭据与签名信任治理**（高风险，待实施）  
   移除当前跟踪的私钥备份，加入强制忽略与 secret scan，设计不破坏现有更新链的签名轮换路径。验收：当前树和新提交不含密钥；扫描为零；旧版到迁移版路径有测试。

2. **Universal、可复现、可公证的发布流水线**（高风险，待实施）  
   构建 Universal 2，生成校验和/SBOM，严格检查 clean tree 与签名身份，支持有凭据时公证/staple、无凭据时明确失败而非伪通过。验收：双架构、重复构建可核验、发布脚本不再 `git add -A` 吞入杂物。

3. **独立加密签名的安全更新协议**（高风险，待实施）  
   更新元数据绑定版本、asset、长度、哈希和独立公钥签名，拒绝降级、截断、多 app、路径穿越与压缩炸弹，失败可回滚。验收：攻击样例测试全拒绝，正常升级/回滚 smoke 通过。

4. **Swift 6 严格并发与 HID 生命周期串行化**（高风险，待实施）  
   消除共享可变状态竞态，确保 apply/reapply/restore 顺序确定。验收：Swift 6 complete strict concurrency 零警告；并发测试通过；退出必恢复 HID 基线。

5. **关键链路端到端、故障注入与安全解析门禁**（高风险，待实施）  
   覆盖捕获→落盘→搜索→粘贴→还原，以及损坏、满盘、权限拒绝、退出竞态和恶意 payload。验收：关键非 UI 核心覆盖达到 80%，关键状态机分支达到 90%，故障样例不丢既有数据。

6. **性能 SLO、隐私安全可观测性与机器化 Doctor**（中风险，待实施）  
   建立热键首帧、搜索、滚动、空闲 CPU、RSS 门禁与脱敏诊断；Doctor hard failure 返回非零并支持 JSON。验收：5,000 条历史目标为首帧 P95≤50ms、搜索 P95≤30ms、空闲 CPU≤0.5%，回归超过 10% 失败。

### B. 剪贴板可靠性、性能与隐私

7. **事务型可恢复存储与损坏索引重建**（高风险，已通过）  
   record、payload、队列和索引具备一致提交/恢复语义；损坏内容隔离而非自动删除。验收：截断索引、kill、缺文件后重启不丢可恢复内容，一致性检查为零。

8. **有序写入、编辑不覆盖与有界退出 drain**（高风险，已通过）  
   统一 payload 写序列，消除 insert→edit 旧写覆盖；退出等待已确认捕获落盘。验收：10,000 轮竞态测试永远保留编辑值，正常退出无空壳记录。

9. **有预算的异步捕获管线**（高风险，已通过）  
   按优先类型增量读取，先预算再后台哈希/解析/缩略，延迟 provider 有超时。验收：20/200/500MB 样例主线程单次阻塞<16ms、无 OOM、热键仍响应。

10. **原子粘贴状态机与两阶段队列消费**（高风险，已通过）  
    prepare/place/activate/send/commit 分阶段返回结构化结果，只在可验证边界后出队；失败保留重试。验收：缺权限、缺 payload、目标退出、事件失败时队列不减，成功只减一次。

11. **CAS 剪贴板还原与连续粘贴协调**（高风险，已通过）  
    使用 changeCount compare-and-swap、可取消任务和自适应延迟。验收：还原窗口内用户新复制绝不被覆盖；慢应用和快速连续粘贴顺序稳定。

12. **批量操作预检与全有或全无语义**（中风险，已通过）  
    执行前列出缺失、超限或不兼容条目；默认整批中止，显式确认后才能跳过。验收：选 5 条不会静默只处理 3 条，结果和错误逐项可见。

13. **真实暂停、可靠来源归因与应用级隐私规则**（高风险，已通过）  
    暂停同时停止记录；复制事件尽早快照 source PID/bundle；支持忽略/仅文本/不存图片和严格 unknown 策略。验收：暂停期间零落盘；100 次忽略 app 复制后切换 app 泄漏为零。

14. **Keychain 剪贴板保险库与安全文件策略**（高风险，实施中）  
    payload、全文、缩略图静态加密，Keychain 管密钥，目录 0700/文件 0600，迁移采用 shadow copy+校验+回滚。验收：磁盘不可直接提取正文；密钥缺失进入只读恢复而非删历史；性能回归<10%。

15. **敏感条目 TTL、一次性粘贴与临时隐私模式**（高风险，待实施）  
    识别 concealed/transient 及可配置敏感模式，支持 15m/1h 暂停、超时删除和粘贴后删除。验收：密码/OTP/私钥样例遵守策略，菜单明确显示暂停原因与恢复时间。

16. **全局磁盘预算、低磁盘保护与存储健康**（高风险，待实施）  
    收藏也受硬安全上限，低空间时停止大 payload 但保留小文本，并提前通知。验收：压力测试不突破预算；任何删除可解释且收藏不被静默淘汰。

17. **异步缩略图与文件预览缓存管线**（中风险，待实施）  
    基于解码字节成本的 LRU、预取取消、后台读盘/解码，网络卷与失效文件不阻塞 UI。验收：1,000 张图片滚动流畅，缓存 RSS 在预算内。

18. **可扩展全文索引、查询语言与智能筛选**（高风险，待实施）  
    持久化索引、模糊相关度、拼音、`app:`/`type:`/日期/收藏/队列组合条件及保存筛选。验收：5,000×32K 数据集搜索 P95≤30ms，常驻内存有硬上限，命中高亮正确。

19. **权限与粘贴能力诊断及原位恢复**（中风险，已通过）  
    无辅助功能权限时不关闭面板、不出队、不显示虚假成功；提供一键修复并监听恢复。验收：撤权/授权无需重启，状态与操作结果一致。

20. **完整 UTI、Paste As 与跨应用/多文件互操作**（高风险，实施中）  
    规范化 public 类型，支持原始/富文本/RTF/HTML/纯文本粘贴，多文件拖出不再丢项。验收：Finder、Safari、Pages、Office、终端金样往返；私有类型安全过滤。

### C. 专业剪贴板 UI/UX 与整体体验

21. **响应式单窗剪贴板工作台**（高风险，待实施）  
    将列表与预览改为可调整 split/inspector；窄屏使用内嵌抽屉/详情页，不再取消预览；记忆每屏尺寸。验收：13/14/16 英寸、多屏、刘海、Stage Manager、全屏 Space 均不越界且 100% 可访问预览。

22. **内容自适应 Inspector 与视觉浏览模式**（中风险，待实施）  
    图片网格、文件卡、颜色卡、链接详情，超宽/超高/小图/长文本合理利用空间，并加入本地 OCR/QR 识别入口。验收：视觉截图覆盖 4 类内容；100 张图片首屏密度显著提升；键盘导航一致。

23. **一等 Paste Stack 工作流**（高风险，待实施）  
    把已有队列升级为可见捕获会话：拖动排序、暂停/继续、目标 app、进度、逐项结果、失败重试与撤销出队；HUD 只做反馈。验收：崩溃重启保持状态，失败项不消失且可恢复。

24. **Pinboards、Snippets、标题标签与变量模板**（中风险，待实施）  
    收藏升级为命名集合、颜色、固定顺序、标题/标签/智能集合和变量模板。验收：100+ 项可分组搜索重排；模板粘贴前可预览变量；升级不丢收藏。

25. **统一动作模型、Command Palette 与可发现快捷键**（中风险，待实施）  
    面板、右键菜单、菜单栏、VoiceOver 使用同一动作源；支持动作搜索、Paste As 与冲突提示。验收：所有主要动作均能由鼠标、键盘和 VoiceOver 发现与执行，三处动作一致。

26. **设置窗口信息架构重构**（中风险，待实施）  
    改为侧边栏分区：捕获与隐私、历史保留、面板行为、粘贴、存储维护；摘要卡+渐进披露，窗口可放大。验收：高频设置在首屏或一次导航内，无整页长滚动，危险动作有明确层级。

27. **任务式首次使用引导与可重放教程**（中风险，待实施）  
    真实完成“复制→呼出→搜索→粘贴”，由事件自动推进，失败原位解释。验收：新用户 3 步内完成首次成功粘贴；可跳过、可重放、不会覆盖已有数据。

28. **系统化可访问性与可读性**（中风险，待实施）  
    动态字体、增大对比度、减少透明、Reduce Motion、VoiceOver actions、完整键盘焦点。验收：Accessibility Inspector 无严重项；Reduce Transparency 有实底；200% 文本不截断。

29. **备份、导入导出与可视化恢复中心**（高风险，待实施）  
    提供加密备份、版本化导入、迁移预检、数据库/索引健康、后台维护进度和可恢复异常。验收：备份→清空→恢复内容/收藏/队列一致；损坏备份不污染现库；异常不再静默。

30. **快捷键 Profiles、场景模板与冲突治理**（中风险，实施中）  
    为应用启动和剪贴板动作提供可命名 Profile、批量导入导出、场景模板、实时冲突解释与原子切换。验收：Profile 切换无丢键/重复触发；冲突可定位；导出再导入完全一致。
